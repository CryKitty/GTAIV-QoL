# Paused label artwork

`paused-pricedown.label` contains one fixed raster image of the word **Paused**, rendered in **Pricedown Black** by Typodermic Fonts from the user's supplied `pricedown.zip` (`Pricedown Bl.otf`, PostScript name `Pricedown-Black`). It is not a font, character atlas, glyph library, or text generator. The original font file is not included or uploaded to the repository.

The supplied Desktop EULA v260817 section 2.2 permits distribution of finished static artwork without font software or individually addressable glyphs. This asset is that fixed finished word. Its `QPL1` header is followed by little-endian width/height and zlib-compressed alpha pixels. `tools/embed-pause-label.py` validates and compiles the image into the ASI. The mod only draws the complete image.
