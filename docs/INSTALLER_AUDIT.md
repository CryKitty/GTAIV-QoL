## Public updater and the two-step repository decision

Step 2 copied the cleaned merged tree into a fresh public CryKitty/GTAIV-QoL with main canonical and no archive history. GTAIV-QoL-dev stays private forever; its old files, PRs and history were not rewritten. Private capture identifiers/gameplay times were removed only from this copy. The first commit uses a GitHub private noreply identity. No beta release, tag, Nexus page or environment is published by migration.

UPDATE_SOURCE now points to CryKitty/GTAIV-QoL / main, shared by updater/manifests/Nexus metadata/tag validation. Public CI no longer reads the archive's build91 artifact: only the supplied checksum-verified menu host/licence and matching source inputs are retained under vendor/fusionfix-menu. Full provenance/build instructions are there. Same-version legacy state must refresh updater source/identity before repeat-launch handoff; standalone bootstrap upgrades older revisions too.

The `beta` channel uses no authentication token, includes published beta prereleases, orders numeric versions correctly, validates repository/branch/version/file hashes and avoids downgrading a newer installation. Drafts and missing/wrong assets are skipped. Before a beta release is published, checks report no published update; network/API errors report unavailable without asking for a private token. Initial installation can continue from the verified Nexus payload.

Existing `dev` channel/menu choices are preserved after the one-time installer migration (UPDATER.md): latest successful build.yml push/workflow_dispatch on the new public repo/main, excluding PRs/forks/failures/in-progress/expired or mismatched artifacts. The older full-release-only channel is retained separately. No polling service, Steam launch-option rewrite or upload-token requirement is introduced.

## Exact fresh-download acceptance checklist

1. Install GTA IV Complete Edition 1.2.0.59 in Steam. Launch/close the game once through Steam so its prefix exists. Close GTA IV before setup.
2. In Deck Desktop Mode, extract the entire Nexus ZIP into one folder (also test a folder name with spaces). Run **Install-GTAIV-QoL.desktop**, accepting Execute/Trust. Do not extract/copy the inner mod payload into the game by hand and do not download a separate updater.
3. Confirm the GUI verifies its bundled copy and checks public updates. Until a beta release is published, a no-published-update check should still allow bundled installation with **no private/login-token prompt**.
4. Confirm Steam/SD game discovery, choose the correct installation if several are found, and check the displayed dependency list. With everything already present, it should not overwrite recognized dependencies or personal settings.
5. For missing files, either use **Set up** for the current requirement, or use the Get buttons and save the supported downloads to Downloads. CE patch uses its author's page. For manual runtime download use **Download supported Microsoft X86 installer**, not an arbitrary newer/different file. Do not unpack/place dependency files yourself.
6. Click **Retry / check downloaded file**. Setup detects the existing app prefix and Steam-configured tool automatically. Check that downloaded loader/ScriptHook/CE/FusionFix files are placed automatically, original downloads remain, runtime installs/re-checks in that prefix and native loader setup is verified. No other prefix or Steam launch options should change. A partial/bad download or unsupported conflicting host must stop safely, not report ready.
7. With all checks green, click **Install GTA IV QoL**. Confirm success, both ASIs/shared settings/verified menu host installed, duplicates backed up/removed, and **Update GTA IV QoL** created. Confirm no log-upload credentials/config were created for a fresh user.
8. Launch the game and check all seven components using QoL/Audio menus: manual/police ribbons in On/Off modes, RoadNav turn cues, Map Autozoom then manual map movement, voiced cutscene pause/resume and Cutscene Audio, Compass waypoint/phone/health behavior, rear-seat Taxi FOV. Keep beta/rare unconfirmed auto-shoot limitations; this installer work does not fix that issue.
9. Close GTA IV. Launch the installed **Update GTA IV QoL** shortcut; no original archive or separate updater download should be needed. Re-run the same installed-version launcher as well; it should check dependencies then hand off rather than reinstalling everything.
10. **After separate publication approval only:** publish a newer beta with matching GTAIV-QoL-update.zip. The shortcut must find/download/verify/install it without a token, preserving menu settings. Confirm beta.10 sorts after beta.2, drafts/invalid assets are skipped and an older published beta does not downgrade a newer install. Migrated development users must select the new repo/main non-PR CI builds.
