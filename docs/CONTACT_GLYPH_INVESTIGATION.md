# Mission-contact glyphs: b112 source/reproducer comparison

The supplied trace identifies TLAD, focuses sprite 101 repeatedly, validates the
name table globally, and counts fallback icons. It does not record the individual
failed texture name or the artwork's letter. It cannot prove that the counted
fallback is Jim or identify a post-fix Deck draw. No such evidence is invented.

IV-SDK eRadarSprite identifies 95..109 as EPISODE_BLIP_1..15. The game's TLAD/
TBoGT taxi script requests GET_TEXTURE(blips, "episode_blip_7") for sprite 101;
other episode contacts use the other episode_blip resources. Those are game
textures, not text initials generated by this mod. A generic radar_level entry
must not replace the canonical episode resource.

The exact rejecting expression is strncmp(text,"radar_",6)!=0. It predates both
PRs and is present in the earliest available source snapshot. PR #27 changes
route colours and reads episode identity; PR #28 changes HUD masks/startup.
Neither changes name validation, texture lookup or icon draw. No honest source
bisect can name one as introducing this predicate. A live runtime interaction
cannot be ruled out by source equivalence, but it is not evidence found here.

Fix: accept bounded episode_blip_1..15 names as well as radar_ names, resolve
known episode sprite slots to the canonical resources used by native scripts,
and keep meaningful native radar names for other sprites. Known-but-loading
textures retry as pending instead of showing a generic unknown dot. Unknown
icons alone keep generic symbols. Every sprite's first draw/mode transition logs
its actual resolved name, readiness and completed native draw-call request.

Controlled executable before/after selection records for the same episode icon:

    before sprite=101 name=episode_blip_7 rejected=1 draw=symbol(.)
    after  sprite=101 name=episode_blip_7 rejected=0 draw=texture

These are deterministic production-helper test records, NOT captured Deck
before/after pixels or proof that the attached focus was Jim. The game supplies
the correct artwork/initial; this change does not fabricate J or any other
letter. Windows/portable tests cover all 15 slots, base contact names, generic
placeholders, pending/unknown separation and invalid strings. Deck acceptance:
check multiple contacts (including Jim when available) across all episodes,
then inspect Compass glyph draw records for real texture requests/fallback=0.
