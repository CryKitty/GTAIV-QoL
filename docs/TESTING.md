# Cutscene pause checks

Close GTA IV and run the installed Update GTA IV QoL Desktop shortcut. No manual copying or settings edits are needed.

1. During a voiced cutscene, press Esc or controller Start once. Dialogue, actors and camera motion should stop together.
2. Check the blurred frame and Pricedown **Paused** label at the bottom right.
3. Wait longer than 15 seconds. It should remain paused; there is no recovery countdown.
4. Press the same control again. Sound and motion should resume together from the same moment. Repeat once to check synchronization.
5. Outside cutscenes, check that Esc/Start still opens the normal game pause menu.
6. Exit normally and allow automatic logs to upload.

The 300% map zoom default and broad logging remain enabled. Focus loss, scene exit and script shutdown still clean up an owned pause. Audio-less scenes and voice-volume sliders are outside the current feature.
